# The Gap

The Gap is a small game for learning vocabulary. Fill the missing word in a sentence. Practice stays in this browser.

## Run

```
python -m http.server 4173 --directory game
```

Open http://127.0.0.1:4173/

The large collections use sentences from [Tatoeba](https://tatoeba.org) (CC BY 2.0).
